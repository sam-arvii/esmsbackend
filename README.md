The Elevator Service Management System (ESMS) is a full-stack service management platform designed to automate elevator maintenance operations, technician dispatching, customer relationship management, invoicing, payment processing, and Annual Maintenance Contract (AMC) management.

Unlike traditional service software, ESMS is designed using modular backend architecture, RESTful APIs, role-based authorization, and scalable database design to support future cloud deployment and AI-powered predictive maintenance.

The project follows modern software engineering practices including layered architecture, database normalization, secure authentication, structured logging, validation, centralized error handling, and maintainable code organization.
